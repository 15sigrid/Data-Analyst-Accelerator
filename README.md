# Junior Data Analyst Career Accelerator

A hands-on 10-week mentorship program (Nov 2026 – Jan 2027) in which I work as a data analyst for **UrbanStyle**, an Estonian e-commerce startup, solving real business problems with real data.

## About this repository

This repository documents my work throughout the program: SQL queries, data cleaning scripts, Python analyses and dashboards. Each week builds on the previous one, from raw data to a final presentation for the company's board.

## Tools

- **SQL / PostgreSQL** (Supabase): querying and cleaning data
- **Python / pandas**: analysis and customer segmentation
- **Power BI**: interactive dashboards
- **Git / GitHub**: version control and portfolio

## Program structure

| Week | Topic | Deliverable |
|------|-------|-------------|
| 0 | Environment setup | GitHub repo + README |
| 1 | SQL basics | Sales data exploration |
| 2 | Data cleaning | Cleaning script |
| 3 | JOINs, multi-table queries | Top customers analysis |
| 4 | Aggregation, KPIs | Business KPI queries |
| 5 | Data visualization | Investor dashboard |
| 6 | Data storytelling | Published dashboard + data story |
| 7 | Python & pandas | RFM customer segmentation |
| 8 | APIs & automation | Automated data pipeline |
| 9 | Career preparation | CV + LinkedIn |
| 10 | Portfolio & final pitch | Board meeting presentation |
